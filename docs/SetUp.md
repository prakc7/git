# Installation of git

- Download from: https://git-scm.com/install/

---

## Check in Powershell or cmd

Using:

```bash
git --version
```

---

## Check for Configurations

```bash
git config --global --list
```

> If missing, setup it by the folowing steps.

---

## SetUp your Configurations

```bash
git config --global user.name "your-name"
git config --global user.email "your-email"
```

Re-check:

```bash
git config --global --list
```

> If it is there. Your setup is done.
